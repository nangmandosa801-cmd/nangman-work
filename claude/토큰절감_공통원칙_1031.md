# 토큰 절감 공통 원칙 (핵심만 — 전문은 프로젝트 문서 claude/토큰절감_공통원칙_1031.md)
1. 대화를 길게 끌지 않는다. 일 덩어리마다 새 창, 이어 갈 내용은 문서에.
2. fork 서브에이전트 금지(대화 전체를 물려받아 수십만 토큰).
3. 반복 일은 스크립트 한 번, 결과는 JSON 몇 줄. 눈으로 보는 확인은 프로그램 검사로.
4. 브라우저는 JS 한 번 · browser_batch로 묶고 스크린샷은 끝에 한 번(scale 0.4). 매번 막히는 곳(네이버 admin 통계)은 시도하지 않고 「자동 조회 불가」.
5. 큰 파일 통째 읽기 금지(grep · 줄 범위 · project_search n=2~3). 도우미 html은 read 말고 파일로. list_triggers · list_scheduled 큰 출력은 파일로.
6. 새 글 확인은 /home/claude/watch/rss_new.py 한 번(없으면 끝). 원고는 큰 모델, 올리기 · 검사 · 숫자 모으기는 작은 모델.
7. send_later로 같은 대화에 알림 걸지 않기. 반복이면 새 창 정기 작업.
