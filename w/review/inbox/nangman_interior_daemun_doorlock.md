# 대문 도어락 교체, 쓰던 문에 번호키만 바꿀 때 볼 것
kicker: 낭만 인테리어 · 도어락
tags: 대문 도어락 교체, 대문 도어락, 도어락 교체, 철문 도어락 교체, 도어락 교체비용

주택이나 빌라 대문에 달린 오래된 도어락이 자꾸 말썽이면 문까지 바꿔야 하나 걱정이 됩니다. 대부분은 문은 그대로 두고 도어락만 바꿉니다.

## 대문 도어락 교체 전에 보는 것

- 지금 도어락 본체 크기 · 고정 구멍 위치
- 문 끝과 손잡이 사이 공간(대문은 좁은 경우가 많음)
- 따로 달린 손잡이를 그대로 둘지
- 철문인지, 문틀이 좁은 철제 틀인지

겉보기 크기가 비슷해도 문 안쪽 고정 구조가 다르면 그대로 안 맞습니다.

## 대문 도어락 교체 사례 · 의정부 단독주택 대문

| 문 | 쓰던 대문(문은 바꾸지 않음) |
|---|---|
| 전 상태 | 붉은 덮개 도어락 + 따로 달린 손잡이 |
| 한 일 | 옛 도어락을 떼고 새 번호키를 맞춰 닮 |

제휴 열쇠팀이 문 크기와 고정 위치를 먼저 재고 맞는 제품을 골랐습니다.

## 도어락 교체 비용 볼 곳

- 제품값과 설치비가 같이인지 따로인지
- 옛 도어락 떼는 값 · 보강판 값이 따로인지
- 출장비가 있는지

## 이럴 때는 부르세요

- 비밀번호 · 비상전원 둘 다 안 먹혀 문이 안 열릴 때
- 새 도어락 구멍이 옛 구멍과 달라 문에 구멍이 드러날 때

## 옛 도어락을 떼어 내면 보는 것

- 옛 구멍 · 나사 자국 위치
- 새 본체를 받쳐 줄 면이 충분한지
- 부품이 들어갈 공간에 걸리는 곳이 없는지

옛 구멍을 그대로 쓸 수 있는지는 떼어 내 봐야 압니다. 그래서 겉모습 사진만으로 「그대로 됩니다」라고 단정하지 않습니다.

## 손잡이를 그대로 둘 때

의정부 대문은 손잡이를 바꾸지 않았습니다. 다만 손잡이가 도어락 바로 위에 있어 번호판 덮개를 올리면 손잡이에 걸리는 구조였습니다. 그래서 덮개가 걸리지 않게 설치 높이와 방향을 맞췄습니다. 번호를 누르는 것뿐 아니라 덮개를 열고 손잡이를 잡는 동작까지 생각해야 합니다.

## 설치 뒤 확인할 것

| 확인 | 이유 |
|---|---|
| 본체가 흔들리지 않는지 | 매일 여닫으며 풀릴 수 있음 |
| 덮개가 걸리지 않는지 | 손잡이 · 문틀과 부딪칠 수 있음 |
| 문을 연 채로 작동 · 닫고 잠금 | 열린 상태에선 되다가 닫으면 걸릴 수 있음 |
| 잠금쇠와 문틀 받이 | 위치가 어긋나면 잠글 때 힘이 듦 |

## 상담할 때 보낼 사진

대문 전체 · 도어락 앞면 · 안쪽 면 · 문틀 쪽 잠금장치 네 장이면 됩니다. 문이 잘 안 닫히는지, 잠글 때 힘이 드는지도 같이 적어 주세요.

## 대문 도어락, 아파트 현관문과 다른 점

| | 대문(주택 · 빌라) | 아파트 현관문 |
|---|---|---|
| 문 | 철문 · 좁은 철제 틀이 많음 | 방화문 규격이 거의 같음 |
| 손잡이 | 따로 달린 경우가 많음 | 도어락과 한 몸이 많음 |
| 날씨 | 비 · 햇빛을 바로 맞음 | 복도 안쪽 |

대문은 비를 맞는 곳이라 방수 덮개가 있는 제품을 고르는 집이 많습니다.

## 출장 지역

제휴 열쇠팀은 의정부 · 양주 · 노원 · 도봉 · 남양주 별내까지 갑니다. 다른 지역은 가까운 열쇠팀을 이어 드립니다.

## 대문 도어락 교체, 이런 때 하세요

- 번호판이 비 · 햇빛에 바래 숫자가 잘 안 보일 때
- 건전지를 바꿔도 금방 닳을 때
- 문이 닫혀도 잠금쇠가 덜 들어가 손으로 밀어야 잠길 때
- 이사 와서 전 집주인이 쓰던 번호를 그대로 쓰기 싫을 때

번호만 바꾸면 되는 경우도 있습니다. 하지만 오래된 제품이라 부품이 단종됐거나 잠금쇠가 닳았다면 교체가 낫습니다.

## 사진 한 장으로 먼저 봅니다

교체가 되는지, 구멍을 더 뚫어야 하는지는 사진으로 먼저 가늠하고, 정확한 것은 출장 때 떼어 보고 정합니다.

## 번호만 바꾸면 될 때

제품이 멀쩡하면 비밀번호 변경 · 등록 카드 삭제만으로 됩니다. 설명서가 없으면 제품 이름 사진을 보내 주세요. 바꾸는 법을 먼저 알려 드립니다.
