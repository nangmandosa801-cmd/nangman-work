## 2. 자료 주고받는 곳 — 구글 드라이브 (PC 쓰지 않음)
Gemini는 같은 구글 계정(nangmandosa801)의 드라이브를 바로 읽는다. 그래서 둘의 공유 자리는 드라이브 「블로그/」 폴더다.
- 「블로그/텍스트/<블로그>」 — Claude 원고 txt(검수 대상). 파일 이름 앞에 브랜드(nangman_interior_ …).
- 「블로그/shorts」 — 영상 · 커버 · 캡션 info.
- 「블로그/장부」 — Claude가 내보내는 장부: 발행 글 목록 · 예약 큐 · 문의 · 계약 장부 · 시공팀 목록(전화번호 빼고). 새 글 쓰기 전 겹침 · 꼬리 링크 확인용.
- 「블로그/검수」 — Gemini 검수 결과 · Gemini가 쓴 원고(파일 이름 끝에 _gemini). 사장이 Gemini 답을 이 폴더에 저장(구글 문서 「드라이브에 저장」).
- 「블로그/_gemini_작업기록」 — 하루 끝 한 줄 기록(날짜 · 브랜드 · 제목 · 상태 · 주소). Claude가 다음 작업 때 읽고 장부에 반영.
- 올리기 · 받기는 Claude 쪽 `gas.py fput|fget|ls`(블로그 우체통). 우체통 설정 전에는 Google Drive 커넥터로 텍스트만 올린다.
- GitHub 저장소(nangman-work)는 Claude 전용 작업 파일. Gemini에게 주지 않는다.

## 3. 하루 흐름 (원고 한 편)
1. Claude: 원고 → 「블로그/텍스트/…」 저장 + 도우미 아티팩트.
2. 사장: Gemini Gem 「낭만 검수」에 「검수: <파일 이름>」 한 줄. Gemini가 드라이브에서 읽고 「통과 / 수정 필요」 표.
3. 수정 필요면 사장이 그 표를 Claude에 붙임 → Claude가 고침(지목한 글만).
4. 통과면 Aside가 네이버 예약 → Claude가 발행 뒤 후속(post_followup.py) · SNS 자동.

## 4. Claude가 멈췄을 때
- Gemini에 「오늘 할 일: ○○」. Gemini는 「블로그/장부」의 발행 목록 · 큐를 보고 이어서 원고 · 캡션을 만든다. 결과는 「블로그/검수」에 _gemini 로.
- SNS는 Upload-Post 예약이 이미 돌고 있으니 손대지 않는다. 새 영상이 필요할 때만 브리핑 9-3(앱에서 손으로 올리기).
- Claude가 돌아오면 「블로그/_gemini_작업기록」을 읽고 장부 · 일정표에 반영, 겹친 게시 · 규칙 위반 점검.

## 7. Gemini를 「싼 일꾼」으로 쓰기 — API로 Claude 토큰 줄이기 (11/3 10:54 추가)
작업 공간에서 Gemini API(generativelanguage.googleapis.com)에 닿는다(키만 있으면 됨). 그래서 사람이 붙여 넣는 대신 스크립트가 Gemini Flash를 직접 부른다. 반복 · 대량 일을 Gemini가 하고, Claude는 판단 · 원고 · 통제만 한다.

| 일 | 누가 | 어떻게 |
|---|---|---|
| SNS 캡션 초안(틱톡 · 인스타 · 유튜브 · 스레드 카드 6장 문장) | Gemini Flash | 「전 채널」 작업이 글 본문을 넘기면 캡션 JSON으로 받음 → Claude(소넷)는 올리기만 |
| 원고 1차 검수(금지 표현 · 지어낸 숫자 · 키워드 배치) | 스크립트 + Gemini Flash | 브리핑 11장 점검표를 프롬프트로 고정. 「수정 필요」 줄만 Claude가 봄 |
| 티스토리 · 블로거 요약본 | Gemini Flash | 네이버 원문 → 겹침 없는 요약 + 표 하나 |
| 클립 장면 문장 다듬기(13자 안 · 큰 글자용) | Gemini Flash | post_followup.py 안에서 소제목을 짧게 |
| 제목 후보 5안(자동완성 실측 결과를 넣어) | Gemini Flash | Claude가 그중 고름 |
| 분위기 그림(글자 없는 배경 · 창고용) | Gemini 이미지 | 글자 · 숫자 그림은 지금처럼 PIL |
| 원고 본문 · 데이터 분석 · 판단 · 일정 · 통제 | Claude | 그대로 |

- 도구: `/home/claude/helper/gemini.py "<할 일>" < 입력` → JSON 한 줄(만들 예정 · 키 받은 뒤).
- 키 보관: Google AI Studio 무료 키를 블로그 우체통(Apps Script)의 스크립트 속성에 넣고 `gas.py gemini …` 로 부르는 방식이 안전하다(키가 채팅 · 저장소에 남지 않음). 우체통 설정 전이면 사장이 /home/claude/gas/gemini_key 파일에 직접 넣는다(채팅에 쓰지 않음).
- 하루 무료 한도 안에서 돌린다. 한도를 넘거나 오류면 그 일만 Claude가 한다.
- Gemini가 만든 글은 그대로 내보내지 않는다. 금지 표현 검사 스크립트를 한 번 더 통과해야 올라간다.
