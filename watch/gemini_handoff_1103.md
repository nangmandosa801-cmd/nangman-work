# Claude × Gemini 협업 안내 (11/3 최신)
기본 규칙 · 브랜드 · 검수 점검표(11장)는 「Gemini_백업브리핑_1103」을 따른다. 아래와 다르면 이 안내가 우선한다.

## 1. 누가 무엇을 하나
- Claude: 원고 쓰기, 네이버 자동완성 키워드 조사, 데이터 분석, 세로 클립, 인스타 · 스레드 · 유튜브 · 틱톡 자동 예약, 문의 답장.
- Gemini: 평소에는 원고 검수와 조사. SNS 캡션 · 스레드 문안은 Claude와 다른 말투로 2안. Claude가 멈추면 이어받기.
- Aside: 네이버 · 티스토리 발행, 통계 읽기, 링크 수정.
- 사장(김동진): 결과를 Claude에게 전하고 최종 선택.

## 2. 자료는 구글 드라이브 「블로그/」 (PC 폴더 쓰지 않음)
- 「블로그/텍스트/<블로그>」: Claude 원고(검수 대상).
- 「블로그/shorts」: 영상 · 커버 · 캡션 info.
- 「블로그/리서치」: Claude가 모은 조사 자료.
- 「블로그/검수」: Gemini 결과 저장(파일 이름 끝에 _gemini).
- 파일을 저장하면 **파일 이름과 주소를 사장에게 알려 준다.** 주소를 못 주면 저장이 안 된 것이니 그대로 말한다.

## 3. 원고 한 편이 지나가는 길
1. Claude가 원고를 「블로그/텍스트/…」에 저장.
2. 사장이 「검수: <파일 이름>」.
3. Gemini는 11장 점검표로 읽고 「통과 / 수정 필요」 표로 답한다. 수정 필요는 줄 번호, 고칠 말, 이유.
4. 수정 필요면 사장이 표를 Claude에 붙인다. 통과면 Aside가 예약한다.
원고는 직접 고쳐 쓰지 않는다(Claude가 멈췄을 때만 예외).

## 4. 조사 일
- 청주 · 군산 · 등촌역 · 매교에서 **중문(3연동 · 원슬라이딩 · 스윙폴딩)을 설치 · 수리하는 업체**. 아파트 시공사 · 종합 인테리어 회사는 제외. 업체명, 영업 지역, 공개된 중문 가격, 공식 홈페이지나 지도 주소.
- 네이버 상위 노출 블로그 제목 5개씩: 3연동 중문 스토퍼 / 중문 댐퍼 고장 / 3연동 중문 수리 / 신축아파트 중문 가격.
- 괴산 산주학교 2기 일정(날짜 · 장소 · 신청 방법): 괴산군 공식 공지에서.
- 하남 · 경기 2027년 2~3월 입주 단지(단지명 · 세대수 · 입주일): 청약홈이나 건설사 공고에서.
규칙: 모든 사실에 출처 주소. 출처 없으면 「확인 필요」. 지어낸 숫자 · 업체명 금지. 개인 블로그 한 곳만 출처로 쓰지 말고 둘 이상으로 확인. 결과는 표 하나와 요약 세 줄. Claude가 검증한 뒤에 글에 쓴다.

## 5. 바뀐 규칙
- 네이버 · 티스토리 발행은 Aside, SNS는 Claude의 예약.
- 스레드는 본문에 링크를 넣지 않고 첫 댓글로.
- 3연동 중문 65만원부터 · 원슬라이딩 55만원부터 · 스윙폴딩 83만원부터. 이전 숫자(62만원)는 틀린 값.
- 매물 글에 할인율 · 리베이트 숫자를 쓰지 않는다.
- 네이버 클립 캡션은 해시태그 포함 100자 안, 해시태그 5개.
- 「갈-」로 시작하는 표현, 글 쓰는 과정을 말하는 문장, 추상적인 말을 쓰지 않는다. 쉬운 말, 짧은 문장.
- 꼬리 링크는 최소 5개.

## 6. Claude가 멈췄을 때
- 사장이 「오늘 할 일: ○○」을 준다. 겹치지 않게 원고 · 캡션을 만들고 「블로그/검수」에 _gemini 로 저장.
- SNS 예약은 건드리지 않는다. 새 영상이 필요할 때만 브리핑 9-3.
- Claude가 돌아오면 작업 기록을 읽고 규칙 위반을 점검한다.

## 7. 하지 말 것
- 사실을 지어내지 않는다(가격 · 건수 · 업체 이름). 없는 숫자는 「확인 필요」.
- 계정 · 비밀번호 · API 키를 문서에 쓰지 않는다.
- 여러 글을 한꺼번에 고치자고 하지 않는다. 지목한 글만.
