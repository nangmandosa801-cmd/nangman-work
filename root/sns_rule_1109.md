■ 커버(첫 화면)
1. 첫 화면은 질문형 훅 한 문장. 예) "수리비, 누가 낼까?"
2. 배경은 실제 현장 사진. 남색 글자 카드만 있는 표지는 쓰지 않는다.
3. 위: 상황 한 줄(흰색) → 핵심 질문(노란색, 크게) → 키워드 3개. 예) 아랫집 천장에 물이 샌다면 / 수리비, 누가 낼까? / 윗집 · 보험 · 관리사무소
4. 아래: "○○ 아파트 실제 사례" 노란 배지 + 낭만 인테리어
5. 릴스는 커버를 영상 맨 앞 1~2초에 넣는다(첫 프레임 = 커버).

■ 릴스 구성
1. 시리즈로 묶고 번호를 붙인다. 예) 입주 전 체크 1/10, 겨울 집 고장 시리즈, 단지별 중문 가격
2. 영상 끝에 "다음 편: ○○ / 팔로우하면 이어서 보여요"
3. 단지명 · 지역을 제목에 넣는다(진위역 서희스타힐스, 운정, 검단 등).
4. 블로그 글의 사진은 5장 이상. 3장 이하면 영상이 10초 안팎으로 너무 짧다.
5. 양보다 질. 인스타는 하루 1~2개.

■ 캡션 구조
1줄: 훅 제목(질문형) / 2~3줄: 핵심 사실 2개(숫자 · 책임 주체 · 기간 등 구체적으로) / 글 전체: https://blog.naver.com/champion_chart/<글번호> / 해시태그 5개(주제 3개 + #인테리어팁 또는 #인테리어시공 + #낭만인테리어)

■ 오래된 인기 콘텐츠 다시 만들기
1. 인사이트 30일 조회 상위 중 1~2주 이상 지난 것을 고른다.
2. 같은 블로그 글로 제목 · 커버 · 첫 문장을 새로 써서 다시 올린다. 원본 복사 금지.
3. 비슷한 주제가 같은 날 겹치지 않게, 시기가 있는 글(사전점검 등)은 그 일정 전에.

■ 당근 소식
1. "실제 고장 + 실제 사진" 글이 반응이 가장 좋았다(중문 걸림 글: 조회 26, 채팅 1).
2. 사진에 글자가 적을수록 반응이 좋다 → 첫 장은 실제 사진, 커버 이미지는 두 번째 장.
3. 끝맺음: "사진 한 장 채팅으로 보내 주시면 어디부터 볼지 알려 드려요"
4. 예약 발행이 안 되므로 하루 1개 바로 발행용으로 쓴다.
